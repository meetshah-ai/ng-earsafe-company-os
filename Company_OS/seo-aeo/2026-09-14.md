## How this was computed

window 2026-08-15→2026-09-13 (today−30 → yesterday), dimensions `query,page`. Single page of
14,312 rows returned (< 25,000 cap — no truncation, pagination loop confirmed no second page
needed). GA4 OAuth token exchange + Data API `runReport`, same window, dimensions
`date,landingPage`, metrics `sessions,totalRevenue,transactions`, `dimensionFilter` on
`sessionMedium==organic` (mandatory, applied). Returned `rowCount=2189`, `len(rows)=2189` —
asserted equal, no truncation.

**Reconciliation (asserted in code):** branded+non-branded impressions == site total impressions
(159,965); sum of per-page impressions == site total; sum of per-query impressions == site total;
GA4 sum of per-landingPage sessions/revenue == GA4 grand totals. All four assertions passed.

recomputed as impression-weighted average (`sum(pos*impr)/sum(impr)`), never a plain mean or a

used every prior cycle, per learning-log.md's standing note; "wehear" queries deliberately kept in
the non-branded/PDP-cluster bucket per the constitution's 2026-08-22 correction (WeHear is an
