- **GSC:** OAuth token exchange + paginated Search Analytics (query×page). 16,371 rows returned in a single page (well under the 25,000 cap — no truncation). Site totals: 2,00,588 impr / 2,571 clicks / overall CTR 1.2817% / impression-weighted pos 7.85.
- **GA4:** OAuth token exchange + Data API `runReport` (date×landingPage, sessions/totalRevenue/transactions, `sessionMedium==organic` dimension filter — mandatory, applied). 1,947 rows returned; `len(rows)==rowCount` asserted (1,947==1,947, no truncation). All metric values cast from string to float/int before arithmetic; `date` parsed as `%Y%m%d`.
- **Reconciliation (asserted in code, all passed):** page-level GSC sums (2,00,588 impr / 2,571 clicks) == site total; query-level GSC sums (2,00,588 impr) == site total; GA4 landingPage sums (7,118 sessions) == GA4 total sessions.
