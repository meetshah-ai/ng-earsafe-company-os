## FORMAT & GLOBAL STYLE (set this in every OpenArt generation)
- **Aspect:** 9:16 vertical, 1080×1920.
- **Total length:** ~13s = four ~3s clips + a 1s end card.
- **Look:** realistic **home-video / phone-shot** style, NOT glossy cinematic — relatability beats polish. Warm Indian-home afternoon light, slightly cluttered WFH desk.
- **Energy (state this explicitly — default models render too slow):** HIGH, snappy, comedic timing. Real human **micro-movements** — blinking, breathing, posture shifts, hands reaching — plus subtle **handheld camera shake**. No slow-motion, no morphing.
- **Subject:** the same ~30-year-old Indian man in a casual t-shirt across all four shots (generate Shot 1 first, then use it as the image reference / "consistent character" seed for Shots 2–4 so he stays the same person).
- **Negative prompt (paste into OpenArt's negative field):** `slow motion, warped hands, distorted face, morphing, extra fingers, on-screen text, watermark, brand logos, glossy commercial look, static frozen pose`
