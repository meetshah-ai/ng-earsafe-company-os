## 4. INSTITUTIONAL TRUTHS (never relearn)
1. No-product content reaches ~4.5× more non-followers than product shots.
2. 6-word identity hooks outperform longer hooks.
3. 20+ saves triggers secondary distribution 24–48 hrs later — saves are the top signal; shares-to-stories are the acquisition signal.
4. First 60 minutes is the distribution decision — reply to every comment within the hour.
5. Trending audio used within its first 7 days gives a Reels distribution boost — but forced trend-chasing with low watch-time gets penalised. Match trend to message or skip it.
6. NG EarSafe is a category-education problem: every selling post answers "what is open ear?" AND "why this one?" in 30s.

## 5. PLAYBOOK + TEMPLATES

### 5a. THE DAILY TRENDING-TOPIC TEST (run every session — this is the differentiator)
1. **Scan now:** what is trending in India *today* — IG/Reels audio, formats, memes, news/cultural moments, sport, regional moments. Use WebSearch + Porter signals. Note source + freshness.
2. **Scan the 7-day window:** what trended in the last 7 days that is *still rideable* (audio still climbing, format not yet saturated, moment still live). Flag anything past its peak as "do not ride."
3. **Score each candidate** on three axes: **Reach potential** (how hot), **Brand-safety** (clears stop list, no competitor/celebrity risk), **Category linkage** (can it carry an open-ear / NG message naturally?). Drop anything that fails category linkage — a trend we can't tie to the message is not ours to ride.
4. **Convert to hooks:** for each surviving trend, draft 1–3 hooks that ride the trend AND land a brand-awareness or category-awareness beat. Tag each: `[brand-awareness]` (NG specifically) or `[category-awareness]` (open ear generally) as applicable.
5. **Map to format + tribe + SKU**, attach a Higgsfield/Canva brief, set the target signal, and **queue as drafts** (label reactive ones `[REACTIVE OPPORTUNITY — Xhr window]`).
6. **Log** which trends were ridden / skipped and why, so the learning-log builds a sense of what trend-types convert for this brand.

### 5b. The content cycle (WAT): LEARN → PLAN → CREATE → REVIEW
14-day calendar; each post = tribe + format + caption mode (1–5) + sell stage (1–4) + visual brief + Higgsfield prompt + target signal + hypothesis. One labelled experiment + one reactive slot per sprint. Day 7 + Day 14 review vs hypothesis → log → adjust.

### 5c. Templates
- **Caption modes:** Observer / Nudge / Scene / Wit / Declaration. Hinglish is natural for Wit. Write native registers — never translate.
- **Higgsfield base:** §08 (cool teal / chalk white / deep navy; documentary, not commercial). Real product photo only.
- **Trend-ride brief:** `Trend: … | Freshness: today / N-days-old still-rideable | Score: reach/safety/linkage | Hook(s): … | Linkage tag: [brand|category] | Format/Tribe/SKU: … | Target signal: …`

## 6. STOP LIST / GUARDRAILS
**Never:**
- ❌ Ride a trend that can't carry a category/brand beat, or one already past peak.
- ❌ Post outside the five-color palette or use prohibited vocabulary (§06/§07/§10).
- ❌ AI-generate the product itself — real photos from `Product Images/` (`[[ng-product-image-rule]]`).
- ❌ Python for creatives/overlays — Higgsfield for visuals, Canva for text/overlays/carousels (`[[ng-creative-tooling-rules]]`).
- ❌ Run a regional-language post as the primary feed post without a prior Stories test.
**Always flag before drafting:** competitor naming, public-figure/celebrity reference, posting-skeleton change, any paid amplification.

## 7. GATES & THRESHOLDS
| Condition | Action | Fallback |
|---|---|---|
| Trend fails category-linkage score | do not ride | find a different trend |
| Format underperforms 2 sprints | cut frequency, reallocate to top format | log decision |
| Region/language beats baseline | increase that register next sprint | note signal |
| Reach drops >40% consecutively / Reels stuck <200 | suspected shadowban: 48-hr pause then high-save static reset | flag Meet |
| Post would sell an out-of-stock SKU | hold (stock-before-demand, `COMPANY_STATE.md` §5) | switch SKU or run category-awareness angle |
