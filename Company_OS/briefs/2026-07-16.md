## How this brief was computed
**Pull windows:** Meta and Google Ads pulled daily, 2026-06-18→2026-07-16 (29 days), campaign-level. GA4 traffic pulled as four single-day calls (D, D-1, D-7, D-28), each including `date`, row counts 40/39/33/35 (all ≥25, none truncated). PDP pulled as two single-day calls (D, D-1) with `sessions > 20` filter, 13 rows each. Shopify pulled daily, 2026-06-18→2026-07-16, using `order_total_count` (not `order_count`).

**GA4 reconciliation (ga4_D, printed by compute.py):**
```
sessions  raw=    2,898.00  grouped=    2,898.00
users     raw=    2,724.00  grouped=    2,724.00
revenue   raw=   67,975.25  grouped=   67,975.25
```
All three match exactly — no rows dropped in channel classification.

**Missing data:** Google Ads returned no row at all for 2026-07-09 (D-7). This understates D-7 Google spend/ROAS/revenue in every "vs last wk" comparison that touches Google or blended figures (Google ROAS vs last wk, blended spend vs last wk shows +35.9% partly because D-7 Google spend reads as ₹0 instead of its true value, SC - All Range campaign "vs last wk" is unavailable for the same reason).

**Spot-check of delta direction (rule 4):** Meta ROAS today 8.86 vs yesterday 6.20 → (8.86−6.20)/6.20×100 = +42.998%, printed by compute.py and matches the table's "+43.0%". This is a ROAS delta, not a spend delta (Meta spend actually fell 5.4% over the same period) — confirms the delta column is tracking the value column, not spend.
